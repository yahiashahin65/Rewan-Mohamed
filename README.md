# بورتفليو روان محمد | Rewan Mohamed

موقع شخصي احترافي **عربي أولًا**، ويحتوي نسخة إنجليزية وصفحات SEO متخصصة. مبني من مستندات روان المرفقة وتصميم حسابها المنشور، دون إضافة نتائج علاجية أو شهادات غير موثقة.

## أهم الوظائف

- بورتفليو متجاوب للموبايل والتابلت والديسكتوب، بوضع ليلي ونهاري وتفاعلات سلسة.
- النسخة العربية: `/` — النسخة الإنجليزية: `/en/`.
- سبع خدمات متصلة بـ **14 صفحة SEO مستقلة** بالعربي والإنجليزي: التخاطب، تأخر الكلام، تعديل السلوك، تنمية المهارات، صعوبات التعلم، الانتباه والتركيز، الإرشاد الأسري.
- قابلية العثور على الاسم **Rewan Mohamed** و**Rawan Mohamed** و**روان محمد** ضمن العناوين والبيانات المنظمة. لا يعني ذلك ضمان تصدر نتائج البحث.
- معرض 16 شهادة مختارة من المستندات، مع تكبير الصور وتصفية وعرض المزيد. تم إخفاء أرقام الهوية الظاهرة في الشهادات الأولى.
- نموذج استفسار يجهز رسالة واتساب بعد إدخال الاسم والخدمة ونوع الجلسة والتاريخ الاختياري، دون حفظ البيانات في قاعدة بيانات.
- ملف مهني مختصر قابل للتنزيل (English) بدون تاريخ ميلاد أو رقم قومي.
- إعدادات SEO: `title`, `description`, `keywords`, `hreflang`, canonical, `Person`, `Service`, `WebSite`, FAQ JSON-LD و`robots.txt`. يتم إنتاج `sitemap.xml` تلقائيًا بعد تعريف عنوان الموقع الحقيقي.

## تشغيل الموقع فورًا — بدون تثبيت مكتبات

**المشروع الافتراضي هو نسخة HTML/CSS/JS جاهزة للفهرسة**، ويمكن تشغيلها باستخدام Node.js وحده:

```bash
npm run build
npm run preview
```

افتح `http://localhost:4173`.

### نشره على Vercel

1. ارفع مجلد المشروع إلى GitHub، ثم اختر Import Project في Vercel.
2. Build command: `npm run build`.
3. Output directory: `dist`.
4. الدومين مضبوط افتراضيًا على `https://rewan-mohamed.vercel.app` داخل سكربتات البناء. متغير `SITE_URL` اختياري فقط إذا تغير الدومين مستقبلًا.
5. اعمل Deploy. سيظهر ملف `sitemap.xml` بروابط الدومين المحدد مع canonical وhreflang تلقائيًا.
6. افتح [Google Search Console](https://search.google.com/search-console/)، أثبت ملكية الدومين، ثم أرسل `https://rewan-mohamed.vercel.app/sitemap.xml` واطلب فهرسة الصفحة الرئيسية وصفحات التخصصات.

**مهم:** لا يمكن ضمان ظهور البورتفليو فور كتابة أي تخصص، ولا يمكن ضمان ترتيب معين في Google. الاستهداف هنا للتخصصات الحقيقية المذكورة في الملفات، وتحتاج الفهرسة لبعض الوقت، وترتبط النتائج بالمنافسة والمحتوى والروابط الخارجية.

## رفع المشروع على GitHub ثم Vercel

1. أنشئ مستودع GitHub جديد باسم `rewan-mohamed-portfolio` (يمكن جعله Private).
2. فك ملف ZIP وارفع **محتويات المجلد نفسه** إلى جذر المستودع: `src/`, `public/`, `scripts/`, `package.json`, `vercel.json` وغيرها. لا ترفع ZIP كملف داخل المستودع.
3. في Vercel اختر **Add New → Project → Import Git Repository** واختر المستودع.
4. الإعدادات: **Framework Preset: Other**، **Build Command: `npm run build`**، **Output Directory: `dist`**، **Root Directory: `./`**.
5. من **Settings → Domains** تأكد أن `rewan-mohamed.vercel.app` متصل بنفس مشروع Vercel. لو الدومين مربوط بمشروع آخر، اربطه بالمشروع الصحيح من إعدادات الدومين.
6. بعد النشر تحقق من `/`, `/en/`, `/robots.txt`, `/sitemap.xml` وصفحات الخدمات.
7. اختبر محركات البحث عبر Google Search Console؛ ظهور الموقع في النتائج ليس فوريًا ولا مضمون الترتيب.

بناء وتجربة النسخة محليًا من أي جهاز مثبت عليه Node.js 22:

```bash
npm run build
npm run check
npm run preview
```

## نسخة React المصدرية

توجد نسخة React + Vite + Tailwind باللغة العربية والإنجليزية ضمن `src/App.jsx` للاستخدام عند التطوير مستقبلًا. النسخة الجاهزة للنشر الافتراضية محسنة للعرض المباشر لمحركات البحث دون الاعتماد على JavaScript لإظهار النص الأساسي.

```bash
npm install
npm run dev:react
```

> للتطوير باستخدام React: يمكن بناء `npm run build:react` بعد تثبيت المكتبات، لكن يفضل استخدام `npm run build` عند نشر هذه النسخة لإتاحة الصفحات العربية والإنجليزية كنص HTML قابل للفهرسة.

## تعديل بيانات روان

- الاسم ووسائل الاتصال: `src/content.js` في العنصر `BRAND`، والنسخ النصية في `COPY`.
- الخدمات والأسماء العربية والإنجليزية: مصفوفة `SERVICES` في `src/content.js`.
- صفحات SEO المتخصصة: `scripts/generate-seo.mjs` داخل `topics`؛ يجب أن تعكس المعلومات الحقيقية فقط.
- التصميم: `src/styles.css`.
- الشهادات: `public/assets/certs/`، والبيانات الوصفية داخل `CERTIFICATES`.
- صورة البروفايل: `public/assets/portrait.webp` (مقتطعة من لقطة إنستغرام المرفقة، ويوصى باستبدالها بصورة شخصية أصلية عالية الدقة بعد الموافقة).
- ملف السيرة العامة: `public/Rewan_Mohamed_Professional_Profile.pdf`.
- نموذج واتساب لا يقوم بحجز موعد حقيقي: يحتاج التواصل والتأكيد يدويًا.

## احترام الخصوصية والمهنية

الملفات الأصلية PDF **غير موجودة** ضمن ملفات النشر لأن بعضها يحتوي على معلومات شخصية كرقم قومي وتاريخ ميلاد. المعرض يتضمن صورًا منتقاة فقط مع تمويه البيانات الوطنية الظاهرة. قبل نشر أي صور أو بيانات، تأكد من موافقة روان على نشرها علنًا. ولا تتضمن الصفحة ادعاءً بترخيص طبي أو شفاء أو نتائج مضمونة.


**ملاحظة مهمة:** روابط WhatsApp مخصصة للاستفسار ولا تثبت أي حجز تلقائيًا، كما يجب الحصول على موافقة روان قبل نشر صورتها والشهادات.
